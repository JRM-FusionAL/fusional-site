# FusionAL Logo Design — 2026-07-19

## Goal
A symbol + wordmark logo system for FusionAL (MCP governance gateway for regulated environments), plus a slogan. Assets generated via the brandkit image pipeline, final mark traced to SVG.

## Symbol — "The Fusion Node"
- Two molten streams converge from left and right into a single solid node; one unified stream exits below (stacked lockup) or right (horizontal lockup).
- Geometry built on circular arcs, near-symmetric.
- Colors: one stream molten `#FF4D00`, one gold `#C9A227`, fusing into a white-hot or ink-outlined core on ink `#0A0A0A`.
- Flat vector, no gradients in the final mark. Gradient-feel renders allowed for hero/social imagery only.
- Must reduce cleanly to 16px: two arcs + a dot.

## Wordmark
- "FusionAL" in Space Grotesk, medium-bold, tight tracking.
- "AL" differentiated: molten color or heavier weight (AI + governance ALignment read).

## Lockups
1. Horizontal — symbol left of wordmark.
2. Stacked — symbol above wordmark.
3. Symbol alone — favicon, avatars, GitHub org, PyPI.
- Default on ink black; white/ink variants for light backgrounds.

## Slogan (chosen — revised 2026-07-20)
**"Keep it flowing while always knowing."**
Descriptor line: **"FusionAL — The Governance Gate"**
Concept: molten flow passes through the gate uninterrupted; the white-hot fusion point is an all-seeing eye — nothing is dammed, nothing is unseen.
(Superseded: "Every tool. One gate. Zero surprises.")

## Deliverables
1. Logo concepts sheet (multiple fusion-node interpretations).
2. Refined chosen mark.
3. Lockup sheet (all three lockups, dark + light).
4. Slogan lockup.
5. App-icon / favicon render.
6. Clean SVG trace of the final mark for the site.
